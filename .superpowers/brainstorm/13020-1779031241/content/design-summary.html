All decisions confirmed. Review before we write the spec.

Design Decisions

Auth LayoutZARA-style two-panel — Login left / Register right on one page
Navbar IconsIcons only — Person (Account), Heart (Wishlist), Bag
Account PageSidebar navigation — Orders, Addresses, Profile, Wishlist, Logout
Color VariantsColored circle swatches with color name label + tooltip
Model LanguageAll TypeScript model properties in English
Style ReferenceZARA — minimal, black & white, generous whitespace

New Pages New

🔐
/auth — Login & Register
Two-panel ZARA-style page. Left: email + password login + Google. Right: register form (firstName, lastName, email, password) + Google. Footer included.
👤
/account — My Account
Sidebar with 4 sections: Orders (list with status badge), Addresses (saved shipping/billing cards, add new), Profile (edit name & email), Wishlist (grid of saved products). Guard: redirects to /auth if not logged in.
❤️
/wishlist — Wishlist
Same product card grid as PLP. Heart icon filled for saved items. "Move to Bag" button on each card. Empty state with CTA.

Updated Pages Updated

🏠
Navbar
Add Person icon → /auth (or /account if logged in). Add Heart icon → /wishlist with item count badge. Bag icon stays.
🃏
Product Card
Add heart icon (top-right corner, toggleable). Show brand name below product name. Show average star rating if reviews exist.
👗
Product Detail Page (PDP)
Color swatch selector (circles + label). Size selector now scoped per variant. Add to Wishlist button. "Material & Care" added to accordion. Reviews section at bottom: star average, list of comments, "Write a review" form (login required).
🛒
Checkout
If logged in: show saved addresses as selectable cards, "Use this address" button. If guest: form stays as-is. Price stored as priceAtPurchase per order item.
